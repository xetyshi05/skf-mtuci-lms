# SKF MTUCI LMS

Фронтенд учебного портала МРС СКФ МТУСИ. Приложение позволяет студентам смотреть сводку и результаты, преподавателям работать с ведомостями, а администраторам управлять преподавателями и ведомостями.

## Возможности

- Авторизация пользователей и восстановление сессии по JWT-токену.
- Разделение доступа по ролям: `student`, `teacher`, `administrator`.
- Кабинет студента со сводкой успеваемости и результатами по семестрам.
- Просмотр, фильтрация, экспорт и загрузка ведомостей МРС.
- Загрузка файлов ведомостей в форматах `.xlsx` и `.xls`.
- Административная форма добавления преподавателей.
- Страница профиля с изменением данных, email и пароля.
- Светлая и темная темы интерфейса.

## Быстрый старт

Установите зависимости:

```bash
npm install
```

Запустите dev-сервер:

```bash
npm run dev
```

По умолчанию Vite запускается на `http://localhost:3000`.

## Переменные окружения

Клиент API задается переменной `VITE_API_URL`:

```bash
VITE_API_URL=https://example.com npm run dev
```

Если `VITE_API_URL` не указана, запросы выполняются относительно текущего домена. В dev-режиме Vite проксирует `/api` на `http://lms-api.space` согласно [vite.config.js](/Users/motya/Desktop/programs/skf-mtuci-lms/vite.config.js).

Для локальной настройки можно создать файл `.env.local`:

```env
VITE_API_URL=
```

## Docker

Собрать и запустить контейнер:

```bash
docker compose up -d --build
```

Контейнер публикует:

- `80:80` - HTTP с редиректом на HTTPS.
- `443:443` - HTTPS.

Production-образ собирает приложение на Node.js 20 Alpine и отдает готовые файлы через Nginx. Конфигурация Nginx находится в [nginx/nginx.conf](/Users/motya/Desktop/programs/skf-mtuci-lms/nginx/nginx.conf).

Для HTTPS в контейнере используются файлы:

- [ssl/cert.pem](/Users/motya/Desktop/programs/skf-mtuci-lms/ssl/cert.pem)
- [ssl/key.pem](/Users/motya/Desktop/programs/skf-mtuci-lms/ssl/key.pem)

## API

Приложение ожидает backend с REST API под префиксом `/api`.

Основные используемые группы эндпоинтов:

- `/api/auth/*` - авторизация, выход, текущий пользователь.
- `/api/student/*` - сводка и результаты студента.
- `/api/gradebooks/*` - ведомости, фильтры, импорт, экспорт.
- `/api/admin/teachers` - добавление преподавателей.
- `/api/profile` - профиль пользователя.
- `/api/email/verify/*` - подтверждение email.

JWT-токен хранится в `localStorage` под ключом `token` и автоматически передается в заголовке `Authorization: Bearer <token>`.
